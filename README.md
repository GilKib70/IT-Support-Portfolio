## Ticket Summaries

### 1. Printer Not Responding (Hardware Issue)
Shows steps how to troubleshoot a non-responsive printer by checking physical connections, clearing print queue, restarting Print Spooler.  
Issue resolves after spooler restart and clearing corrupted print jobs.

*See full ticket:* `/Tickets/hardware-issue-printer-not-responding.md`

---

### 2. User Cannot Log In (Incident)
Investigated a Windows login failure.  
Found the user’s account locked in Active Directory due to multiple failed attempts.  
Unlocked account, reset password, and restored access.

*See full ticket:* `/Tickets/incident-user-login-issue.md`

---

### 3. Finance Shared Folder Access (Access Request with Escalation)
User required access to a confidential Finance folder.  
Verified identity, confirmed business need, escalated to Finance Manager for approval, and updated AD group membership.  
Access restored after permissions sync.

*See full ticket:* `/Tickets/access-request-finance-folder-escalated.md`

---

### 5. Shared Mailbox Not Appearing in Outlook (Microsoft 365 Incident)
User could not see a shared mailbox in Outlook.  
Verified permissions in Microsoft 365 Admin Center, refreshed membership, restarted Outlook, and forced profile sync.  
Mailbox appeared successfully.

*See full ticket:* `/Tickets/incident-shared-mailbox-not-appearing.md`
