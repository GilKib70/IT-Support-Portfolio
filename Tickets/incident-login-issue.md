# Ticket: User cannot log into Windows 11 (Incident)

## Symptoms
- User reports "Incorrect password" error.
- Account locked after multiple attempts.

## Ticket Type
Incident

## Troubleshooting Steps
1. Verified username.
2. Checked account status in Active Directory.
3. Reset password.
4. Forced password change at next login.

## Resolution
User successfully logged in after password reset.

## Root Cause
User forgot password after weekend break.
